# Security notes

This site has no production npm dependencies and does not collect or store form submissions. See README.md for the current controls and GitHub Pages hosting limitations. Do not put credentials, private client documents or original working assets in this repository.

For a suspected vulnerability, use GitHub private vulnerability reporting if enabled, or contact the repository owner privately. Avoid publishing credentials or sensitive reproduction data in a public issue.

Keep Node.js and pinned GitHub Actions current. Dependabot proposes weekly Actions updates; review and validate each update before merging.
